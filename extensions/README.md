# extensions/ — নতুন ফিচার এখানে যোগ করুন

কোর ইঞ্জিন (app.py, generator.py ইত্যাদি) লক করা আছে `LOCKED/` ফোল্ডারে।
ভবিষ্যতে নতুন ফিচার বানালে সেগুলো এই `extensions/` ফোল্ডারে আলাদা ফাইলে রাখুন।
কোর ফাইল বদলাবেন না — নতুন ফাইল যোগ করবেন।

নমুনা: `extensions/my_feature.py`, `extensions/my_feature.js`
